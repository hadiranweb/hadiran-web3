# نسخهٔ داخلی برای بازبینی — منتظر تأیید کاربر

## وضعیت

تغییرات ریپوی `hadiranweb/hadiran-web3` تا commit `1ed9ea7661d766245975654de22377534af53eb4` با نسخهٔ داخلی قبلی `f132353` ادغام شدند. شاخهٔ محلی: `feat/sync-upstream-1ed9ea7`.

**Google Drive در این مرحله تغییر نکرده است.** طبق درخواست کاربر، انتقال فایل‌ها و پوشه‌ها به همان پوشهٔ قبلی فقط بعد از تأیید نسخهٔ داخلی انجام می‌شود. هیچ push یا استقرار production نیز انجام نشده است.

## تغییرهای تازه

۱. **خلاصهٔ کاربر:** عضو به‌جای گزارش تفصیلی، خلاصهٔ قابل‌تنظیم آزمون‌ساز را می‌بیند. قالب، پارامتر و متن چندخطی ذخیره می‌شوند؛ پارامتر ناشناخته خالی می‌شود و eval وجود ندارد.

۲. **تفسیر برای آزمون‌ساز:** تب «تفسیر اولیه» برای مالک و نویسندهٔ دارای مجوز خواندن پاسخ‌ها، شامل نتیجهٔ سه‌رنگ، ابعاد و گزارش کامل اضافه شد. تب برای فرد فاقد مجوز نمایش داده نمی‌شود و endpoint پاسخ‌ها همچنان روی سرور کنترل می‌شود. این جداسازی نمایش رابط است؛ قرارداد upstream برای score snapshot در API تلاش خودِ عضو تغییر نکرده است.

۳. **منوی سایت:** بسته‌شدن با کلیک بیرون، انتخاب مسیر، Escape و اسکرول صفحه حفظ/تکمیل شد؛ انیمیشن WAAPI رو‌به‌بالا باقی ماند. اسکرول داخل منوی بلند، خود منو را نمی‌بندد و محتوا جابه‌جا نمی‌شود.

۴. **تلگرام:** ورودی `/hook/<botId>` و خروجی `/bot…` از Worker پشتیبانی می‌شوند. هدر secret و body ورودی به مبدأ منتقل می‌شوند. اتصال دوباره پیام‌های در صف را حذف نمی‌کند. پیام‌های عیب‌یابی نبودن/اشتباه‌بودن secret و نبودن POST نمایان شده‌اند. اتصال واقعی نیازمند انتشار Worker و تنظیم سرور است و در این محیط انجام نشده است.

۵. **نسخهٔ زیرساخت:** مطابق آخرین commit اصلی، Next.js و eslint-config-next از 16.2.6 به 16.4.1 ارتقا یافتند؛ dependency مستقیم جدید اضافه نشده است. package-lock با upstream برابر است و اسکریپت‌های ساخت پرتره و آواتار محلی حفظ شدند.

## اصلاح‌های ادغام

- بخش‌های تازه با رنگ‌های semantic و فونت سایت در هر دو تم هماهنگ شدند.
- مسیر پیش‌نمایش بدون کوکی و ticketها حفظ شد؛ تب جدید از fetch ویژهٔ همین پیش‌نمایش استفاده می‌کند، ولی دادهٔ واقعی پاسخ‌دهندگان را جعل نمی‌کند.
- بارگذاری تفسیر خطای ارتباط را مدیریت می‌کند؛ تعویض pack باعث نمایش state قدیمی نمی‌شود.
- ایرادهای lint در کامپوننت جدید upstream، شامل setState هم‌زمان در effect و JSX داخل try/catch، اصلاح شدند.
- کنترل سخت‌گیرانهٔ تعلق شمارهٔ تلگرام به خود فرستنده و تشخیص فرمان در مرحلهٔ معرف حفظ شدند.
- ویرایشگر فقط‌خواندنی، کنترل‌های واقعی سرور، پرتره و WAAPI، فونت، آواتارها، سه حالت تم، RTL/LTR و چیدمان قبلی حفظ شدند.

## نتیجهٔ بررسی‌ها

| بررسی | نتیجه |
|---|---|
| build بهینه با Next.js 16.4.1، TypeScript، ESLint | موفق |
| رگرسیون API قبلی | ۱۲ گروه موفق |
| API قابلیت‌های همگام‌شده | ۱۳ گروه موفق |
| API مخصوص تغییرات تازه | ۳ گروه موفق |
| آزمون‌های pure برای قالب، گیت، رلهٔ Worker و صف پیام | ۷ گروه موفق؛ HTTP کاملاً mock |
| گفت‌وگوی تلگرام با DB محلی و HTTP mock | ۸ گروه موفق |
| API آواتار و پایداری نشست | ۴ گروه موفق |
| منو/آواتار/ریسپانسیو | ۱۱ گروه، ۵۹ حالت چیدمان موفق |
| رگرسیون مرورگری قبلی | ۹۶ حالت موفق |
| بخش‌های تازه، سه نقش و روشن/تاریک | ۱۱۲ حالت موفق |
| حفظ دارایی‌ها و migrationها | ۱۱ گروه موفق |

در اجرای موفق نهایی مرورگری، exception یا HTTP 5xx در جریان‌های بررسی‌شده ثبت نشد. همهٔ بررسی‌های DB روی PostgreSQL دورریختنی محلی بودند. ۲۰ migration قبلی تغییر نکردند و از صفر اجرا شدند. آزمون‌های ارتقای تاریخی نسخهٔ قبلی در گزارش همان نسخه‌اند؛ در این مرحله migration جدیدی وجود ندارد.

ارتباط واقعی تلگرام/Cloudflare، پیامک، پرداخت و production آزموده نشده‌اند. ساخت فضای شخصی عمومی برای همهٔ اعضا نیز جزو این همگام‌سازی نیست و هنوز پیاده نشده است.
