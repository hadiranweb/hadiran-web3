# تحلیل UI هادیران — اتاق کار روشن × کیت حرکت

تاریخ: ۱۴۰۴-۰۷-۱۴ (۲۰۲۶-۱۰-۰۶)
وضعیت: پیشنهاد؛ هنوز اجرا نشده.
هدف: تشخیص فاصلهٔ ظاهر فعلی با بریف، و غربال کیت `hadiran-motion` برای استفادهٔ اینلاین روی پشتهٔ همین ریپو.

قفل‌ها: مسیر/IA دست نمی‌خورد. shadcn/MUI/GSAP/`thinking-orbs`/`border-beam` اضافه نمی‌شود. dobare و FounderOS قاطی نمی‌شوند. فروشگاه خارج‌باند می‌ماند.

---

## ۱. تشخیص یک‌خطی

سایت از نظر محصول درست است و از نظر حس، قالب Tailwind است.

خانه گفتگو است اما مثل لندینگ با ویجت چت دیده می‌شود. رنگ‌ها `slate-*` و `indigo-*` پراکنده‌اند. تنها توکن برند `--hadiran-mark` است. کیت حرکت یک لایهٔ «wow» از پلتفرم قبلی است؛ با بریف فعلی در سه نقطه برخورد دارد: پکیج جدید، canvas حلقه‌دار، مدت انیمیشن بلند.

کار درست: توکن و ترکیب؛ نه بازسازی محصول و نه drop-in کیت.

---

## ۲. آنچه امروز روی صفحه است

### سیستم بصری

| الان | بریف |
|---|---|
| `body`: `bg-slate-50` / `dark:bg-slate-950` | کاغذ گرم `#f7f6f2` / شب `#07080f` |
| شعاع و سایه موردی روی هر کارت | `--radius-*` و یک سایهٔ نرم |
| Nav شیشه (`bg-white/80 backdrop-blur`) | نوار کاغذیِ کافی‌مات |
| اکتیو ناو: قرص پر indigo | وزن جوهر یا خط علامت |
| آیکون رنگین‌کمانی در چت (indigo / emerald / amber) | Lucide آرام، یک سامانه |
| `/hadiran`: نوار گرادیان `indigo → violet` | پرترهٔ تحریری؛ بدون کاور جعلی |

`HadiranMark` قفل است (SVG + `currentColor`). در صفحه کاشی سرمه‌ای پشت علامت نیست — خوب. Wordmark متن را `slate-900` می‌گذارد نه رنگ علامت.

تایپ: Vazirmatn هست. `prose-reading` برای مقاله هست؛ heading عمومی `leading` گاهی زیر ۱٫۷ است.

حرکت فعلی: تقریباً هیچ، جز `Loader2` چرخان و `transition` دویست‌میلی‌ثانیه‌ای Tailwind. این بهتر از کیت سنگین است؛ خالی است نه غلط.

### خانه `/`

ساختار سرور درست است: H1، lede، لینک جهان‌ها، JSON-LD، بعد `HomeChat`. SEO قفل است.

درد:

- هدر مرکز-بروشور است؛ ستون گفتگو قهرمان نیست.
- چت داخل جعبهٔ خاکستری (`bg-slate-100/50`) است؛ اتاق نیست.
- حباب کاربر پر indigo و سفید — فریاد، نه «accent-soft».
- `justify-start` کاربر / `justify-end` دستیار روی `dir=rtl` یعنی کاربر راست و دستیار چپ (الگوی پیام‌رسان). بریف نگفته برعکسش کنیم؛ فقط رنگ و شعاع نامتقارن.
- Composer یک `input` تک‌خط است؛ دکمه `absolute left` — این left را طبق بریف نگه می‌داریم.
- لودینگ: اسپینر Lucide، نه سه نقطه.
- ارجاعات: تگ آب‌نباتی چهاررنگ.

جزیرهٔ کلاینت فقط `HomeChat` است. این را زیاد نکنیم.

### ناو و فوتر

ناو: آیکون+برچسب، قرص indigo، شیشه. لینک‌ها درست‌اند (اکوسیستم، درباره من، دانشنامه، آزمایشگاه، دوره‌ها، فروشگاه). میز در ناو عمومی نیست.

فوتر: ردیف نقشهٔ سایت. بریف می‌خواهد آرام‌تر: علامت + یک خط + یک ردیف لینک بدون وزن بصری.

### بقیهٔ سطوح عمومی

- `/ecosystem`: هنوز لندینگ است (H1 بزرگ، آمار در گرید). باید نقشهٔ چهار جهان باشد؛ شمارش فرعی.
- `/hadiran`: کارت پروفایل + بنر گرادیان — نزدیک لینکدین. اگر آواتار خالی است، علامت بزرگ نه نوار بنفش.
- دانشنامه / لب / دوره / موضوع: کارت `border-slate-200 bg-white shadow-sm` تکراری. یک زبان کارت کافی است.
- `/contact`: فرم ندارد — قفل سالم است.
- `/shop`: نیت درست (فیزیکی/مجازی، پرداخت بیرون). ظاهر هنوز قالب است نه تحریری.
- `/signin`: از همه آرام‌تر است؛ با توکن جمع می‌شود.
- `/workspace`: slate متراکم؛ عمداً آخر و فروتن.

## ۳. کیت حرکت — غربال

منبع: `hadiran-motion.zip` (۹ کامپوننت + `motion.css` + هوک). README می‌گوید `npm install gsap thinking-orbs border-beam` و پوشه را کپی کنید.

این با سه قفل پروژه نمی‌خواند:

1. بریف: پشتهٔ UI جدید نه؛ «CSS + Tailwind 4 + lucide».
2. شما: قطعه را **اینلاین** با پشتهٔ همین پروژه.
3. بریف حرکت: ۱۸۰–۲۲۰ms، fade و کمی `translateY`؛ ممنوع: bounce، حلقهٔ خودکار، تار عنکبوت ذرات، canvas سه‌بعدی / پس‌زمینهٔ WebGL. `custom cursor` هم ممنوع.

پس کیت را به `src/hadiran-motion` نمی‌آوریم و peerها را نصب نمی‌کنیم.

### قطعه به قطعه

| قطعه | وابستگی | حکم | دلیل |
|---|---|---|---|
| `motion.css` (rise، chat-in، shimmer) | هیچ | **اینلاین با کوتاه‌کردن** | نفس است نه نمایش. مدت را به ۱۸۰–۲۲۰ms و easing بریف بیاور. |
| `useReducedMotion` | هیچ | **اینلاین** | هوک ۱۰ خطی؛ همهٔ حرکت باید به آن یا media CSS وصل باشد. |
| `ChatRow` | GSAP | **ایده بله، GSAP نه** | معادل: کلاس `chat-in` روی حباب جدید در `HomeChat`. |
| `HomeIntro` | GSAP | **ایده بله، GSAP نه** | استگر CSS روی هدر خانه. H1 در HTML سرور می‌ماند. |
| `Reveal` (IO + rise) | هیچ | **محدود / ترجیحاً نه روی لیست** | بریف: لیست‌ها بدون JS کلاینت اضافه. خانه اگر لازم شد CSS خالص. |
| `ProgressiveBlur` | هیچ (CSS) | **بله، یک لبه** | پایین ستون چت / بالای composer. شیشهٔ سراسری نه. |
| `ThinkingStatus` | `thinking-orbs` + canvas | **نه** | بریف صریح: سه نقطهٔ آرام. |
| `BeamComposer` | `border-beam` | **نه پکیج** | رینگ فوکوس `--ring` دور composer؛ در loading یک خط نرم CSS. |
| `WordReveal` | هیچ | **نه روی H1/lede** | متن را خالی می‌کند، تا JS `opacity:0` است، LCP/SEO خانه را می‌زند. «layout on first paint» هم ممنوع است. |
| `AtmosphereFolds` | canvas + rAF حلقه | **نه** | پس‌زمینهٔ canvas متحرک. جایگزین بریف: wash شعاعی CSS ۴–۶٪ فقط روی `/`. |
| `PointerTrail` | canvas ذرات موس | **نه** | تار عنکبوت + حس cursor سفارشی. |

جمع: از کیت **نفس چت و فوکوس composer** را برمی‌داریم. لایهٔ اتمسفر/ذرات/اسپینر canvas را نمی‌آوریم.

## ۴. آنچه باید ساخته شود (نه کیت، نه دیزاین‌سیستم)

ترتیب بریف، بدون مسیر جدید:

1. **توکن در `globals.css`**  
   `--bg --bg-elev --ink --muted --line --accent --accent-fg --mark --radius-sm/md/lg --shadow-sm --ring`  
   دارک با همان `@custom-variant` رسانه‌ای. `--hadiran-mark` و `.hadiran-mark` نشکند.  
   کی‌فریم کوتاه: `hadiran-rise`، `hadiran-chat-in`، سه نقطه، shimmer فقط هنگام فکر کردن (با `prefers-reduced-motion: none`).

2. **چند primitive کوچک** زیر `src/components/ui/` — نه پکیج دیزاین.  
   `PageShell`، `PageHeader`، `Surface`، `EmptyState`. دکمه اگر لازم شد همان کلاس توکنی، نه سیستم variant کامل.

3. **خانه اول**  
   اتاق تمام‌قد. هدر فشرده: علامت، H1 یک خط، lede، pill جهان‌ها بدون فریاد آیکون. ستون چت قهرمان. Composer چسبیده به پایین ستون. حباب کاربر accent-soft، دستیار کاغذ، شعاع نامتقارن. ارجاعات chip تحریری یک‌رنگ. لودینگ سه نقطه. textarea ۱–۴ خط اگر ساده باشد.

4. **Nav / Footer**  
   ناو مات‌تر، لینک دسکتاپ بدون فریاد آیکون (موبایل آیکون می‌ماند). اکتیو = جوهر یا underline علامت. فوتر سبک.

5. **بعد:** اکوسیستم → هادی (حذف گرادیان) → دانشنامه/لب/دوره/موضوع با همان کارت → فروشگاه با همان توکن نه گرید بازار → تماس (بدون فرم) → ورود.

6. **میز آخر.** متراکم، روشن، بدون سایدبار ۲۰ آیتمی.

## ۵. آنچه عمداً دست نمی‌خورد

- URLها، canonical، `?topic=` فقط فیلتر، `/hadiran` شخص، `/` گفتگو.
- قرارداد `HomeChat`: `/api/chat`، `hw3-conversation-id`.
- OTP / JWT / اسکیما / `ci.yml` / `liara.json` / مایگریت.
- متن جعلی، دورهٔ ساختگی، تلفن ساختگی.
- CSS کلبهٔ dobare، زرین‌پال، iframe دست‌دوم.
- فونت نمایش دوم، عکس استوک، کاشی پشت علامت.

## ۶. ریسک

- **LCP خانه:** هر `opacity:0` قبل از JS روی H1 ممنوع. حرکت ورود فقط تزئینی و بعد از رنگ.
- **RTL composer:** `left` دکمه را به `inline-start` عوض نکنیم مگر padding اینلاین درست آزمایش شود.
- **لیست‌ها:** `Reveal` با IO یعنی جزیره روی هر کارت — وزن بی‌دلیل. نکن.
- **دارک:** هر سطح روشن باید جفت رسانه‌ای داشته باشد؛ توگل تم لازم نیست.
- **فروشگاه:** فقط پوست. قیمت روان‌شناختی و OOB دست نخورد.
- **کیت را در git نگذار.** مرجع پیوست است؛ کد مفید کپی‌شده و سازگار می‌شود.

## ۷. تعریف تمام‌شدن این برش UI

- `/` هنوز گفتگو است؛ H1 و لینک جهان در HTML سرور.
- حس اتاق کار روشن، نه قالب slate/indigo.
- علامت با طرح OS رنگ عوض می‌کند؛ کاشی پشتش نیست.
- `/contact` بدون `<form>`.
- میز در ناو عمومی نیست.
- دانشنامه/لب/دوره/فروشگاه خالی، طراحی‌شده‌اند نه شکسته.
- بدون وابستگی npm جدید.
- typecheck همان دروازه.

پیشنهاد برش اول اجرا (وقتی بگویید شروع): فقط توکن + خانه + Nav/Footer. بقیه صفحات در برش‌های بعد با همان زبان.
