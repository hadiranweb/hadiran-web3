# شبکهٔ معرف

- مسیر `/workspace/network` فقط برای مدیر است. API جدید `/api/workspace/network/overview` همان مجوز را در سرور بررسی می‌کند؛ قرارداد قدیمی `/api/workspace/network` بدون تغییر حفظ شده است.
- منبع رابطه فقط `accounts.referred_by_account_id` است. گره از حساب فعالِ دارای کد عمومی معتبر می‌آید؛ هیچ کد تازه، رابطه، وزن تحلیلی یا دادهٔ جایگزین ساخته نمی‌شود.
- پاسخ فقط نام، نقش، کد عمومی و مرجع عمومیِ معرف را دارد؛ شناسهٔ داخلی، تماس، پول و پاسخ آزمون در projection خروجی نیستند.
- خواندن در تراکنش repeatable-read/read-only است. snapshot زمان موفق واقعی دارد و API خصوصی no-store است. خطا/نبود DB با شمارش و زمان null برمی‌گردد.
- نمای اولیه حداکثر ۲۰ ریشه، هر گراف حداکثر ۱۲۰ گره و عمق انتخابی ۱ تا ۴ دارد. دریافت فرزندان مرحله‌ای و محدود است؛ قطع‌شدن نما صریح نمایش داده می‌شود. فهرست عمومیِ حساب‌های مجاز، شمارش کامل و صفحه‌های ۲۰تایی دارد.
- جست‌وجوی نام/کد و نقش، فهرست را در سرور فیلتر و گره‌های نامنطبقِ بوم را کم‌رنگ می‌کند؛ اتصال‌های زمینه حذف یا بازسازی نمی‌شوند. انتخاب شاخه ادامهٔ واقعی همان حساب را می‌خواند.
- حلقه و خودمعرفی در همان نمای بارگیری‌شده تشخیص داده می‌شوند؛ نه ادعای اعتبارسنجی کل شبکه. والدِ غیرفعال یا بدون کد معتبر «ثبت نشده» قلمداد نمی‌شود.
- SVG بومی و درخت متنی از همان snapshot ساخته می‌شوند. چیدمان حلقه‌ای فقط جای‌گذاری است؛ رنگ فقط نقش را نشان می‌دهد. شبیه‌سازی نیرو، حرکت دائمی و وابستگی تازه وجود ندارد.
- زوم/جابه‌جایی، کلیدهای جهت، +/− و Home، جزئیات با dialog بومی و نمای گستردهٔ محدود به viewport موجودند. Escape ابتدا جزئیات، سپس نمای گسترده را می‌بندد. نمای گسترده درخواست Fullscreen مرورگر نمی‌کند.
- آزمون‌ها روی PostgreSQL محلی و حساب‌های آزمایشی‌اند؛ سنجش تولید، استقرار و انتقال Drive انجام نشده‌اند.
