# نمونهٔ مستقلِ پرسه‌زنی هدفمند

وضعیت: آمادهٔ بازبینی داخلی؛ نه جایگزین صفحهٔ اصلی و نه انتشار روی محیط اصلی.

برای مرور تعاملی از پنل Live Preview سرویس «Hadiran — garden preview» در پورت ۳۰۰۲ و مسیر `/garden-preview` استفاده شود. دسترسی مستقیم و بدون احراز پنل به hostname محیط به‌درستی در لایهٔ زیرساخت با 403/traffic-access-token متوقف است؛ توکن در کد یا فایل بازبینی درج نمی‌شود. درخواست محلی با همان Host عمومی 200 است.

- صفحه: `/garden-preview`، عمومی و `noindex, nofollow`؛ بدون اضافه‌شدن به منوی اصلی.
- دادهٔ قابل بررسی: `GET /api/garden-preview`، بدون cache؛ سایر متدها 405.
- دو ورودی: مسئله با **همان HomeChat موجود و فعال از ابتدا**؛ پرسه با خواندن در همان صفحه. بستن بخش گفت‌وگو آن را unmount نمی‌کند؛ فرم و endpoint موازی ساخته نشده است.
- disclosure بومی `details/summary`؛ Enter/Space/لمس، نشانگر واضح و آدرس مستقل موجود `/knowledge/[slug]` برای هر نوشته. ورودی‌های دارای hash از NextLink استفاده می‌کنند تا Browser Back محتوای درست را برگرداند.
- پیوند موضوع فقط از رابطهٔ واقعی `knowledge_topics`، با جلوهٔ زیرخط یکسان برای pointer و focus؛ هیچ ارتباط فکری یا گراف عمومی ساختگی تولید نشده است.
- انتخاب تصادفی فقط از حداکثر ۱۲ نوشتهٔ همین snapshot؛ در صورت وجود بیش از یک نوشته تکرار متوالی ندارد. تعداد دامنهٔ انتخاب در رابط نوشته شده؛ وعدهٔ انتخاب از تمام دانشنامه نمی‌دهد.
- «امانت باشد دستت.» پس از کپی، بدون جلوگیری از copy بومی یا دستکاری clipboard. دکمهٔ کپی فقط متن خواندنی همین بخش را کپی می‌کند؛ شکست آن پیام متفاوت دارد. متن انتخاب‌شده ذخیره یا ارسال نمی‌شود.
- فقط WAAPI؛ reduced-motion حرکت‌های جدید را خاموش می‌کند. انتهای آرام، بدون exit intent یا پیام مبتنی بر مکث؛ footer و navigation عمومی محفوظ‌اند.

## مرز داده

خوانندهٔ server-only در تراکنش read-only/repeatable-read، **همان `publicKnowledgeFilter` موجود** را اعمال می‌کند: memory item متصل، `aiIndexable=true`، `lifecycle=approved`، `visibility=public`.

حداکثر ۱۲ نوشته، ۶۰۰ نویسهٔ خلاصه و ۴۰۰۰ نویسهٔ بدنه از SQL؛ متن بریده‌شده صریحاً مشخص است و صفحهٔ کامل پیوند دارد. حداکثر ۹۶ رابطهٔ موضوع برای همین شناسه‌ها خوانده می‌شود و حداکثر سه موضوع در هر کارت نمایش می‌یابد. شناسه‌های داخلی و دادهٔ حساب/معرف/مالی/بازبینی خصوصی serialize نمی‌شوند. snapshot شامل زمان واقعی تراکنش و تعداد واقعی نتیجهٔ فیلتر است. تغییر وضعیت انتشار در درخواست بعدی اعمال می‌شود؛ این یک snapshot است، نه سامانهٔ پاک‌کردن نسخه‌های قبلاً دریافت‌شده.

دیتابیس در دسترس و خالی: `source=live,total=0`. دیتابیس غایب/خطادار: `unavailable/error,total=null,asOf=null` و API با 503. دکمهٔ تصادفی غیرفعال است؛ fallback محتوایی وجود ندارد.

«انتشار عمومی» مدرک آزمون میدانی، کیفیت یا تعداد بازبینی نیست. فقط نوع ثبت‌شدهٔ نوشته و تاریخ واقعی `knowledge.updatedAt` نشان داده می‌شود؛ هیچ شمار بازبینی، برچسب خام/آزموده یا تاریخچهٔ فرضی نداریم.

HomeChat موجود **می‌تواند گفت‌وگو را در سرور ذخیره کند**؛ اطلاع در کنار آن آمده است. ادعای «هیچ ردیابی نیست» وجود ندارد. آزمون نبود نوشتن، محدود به تعامل‌های جدید خواندن/hover/کپی/انتخاب/مکث است؛ بازگردانی گفت‌وگوی قبلی و لایهٔ احراز هویت رفتار موجود خود را حفظ می‌کنند. تشخیص قطعی، امتیازدهی فرد یا تغییر موتور پاسخ‌گویی اضافه نشده است.

## دادهٔ آزمایشی و اجرا

سه متن در تصاویر و سرور محلی، **صریحاً آزمایشی** هستند و فقط در PostgreSQL محلی QA ساخته شده‌اند؛ نوشتهٔ واقعی محیط اصلی معرفی نمی‌شوند. برنامه محتوای نمونهٔ hard-coded ندارد. fixtureهای منفی خصوصی/پیش‌نویس/ردشده/غیرقابل‌نمایه/بدون اتصال در پاسخ و DOM نیستند. scriptها فقط دیتابیس نام‌دار QA روی 127.0.0.1 را دست‌کاری می‌کنند؛ انتقال fixtureها به محیط اصلی لازم نیست.

```sh
node qa/garden_api.cjs
node qa/garden_unit.cjs
PYTHONPATH=/tmp/hadiran-qa PLAYWRIGHT_BROWSERS_PATH=/home/user/.cache/pw-browsers python qa/garden_browser.py
python qa/build_garden_review.py
```

QA: API پنج گروه؛ unit چهار گروه با خطای تزریق‌شده؛ مرورگر ده گروه، ۲۴ حالت روشن/تاریک و باز/بسته در ۳۲۰ تا ۱۹۲۰، متن ۲۰۰٪ در ۳۲۰، Clipboard واقعی، reduced-motion، برگشت از صفحهٔ مستقل، صفر خطای hydration/JS؛ فقط یک POST صریح به API موجود چت. قرارداد قدیمی گراف معرف و ۱۲ گروه preservation نیز دوباره بررسی شدند. `typecheck`, `lint`, `build` موفق‌اند.

## اندازه، نه وعده

مرجع دقیق `qa/garden-performance.json`: مرورگر سرد با سه متن آزمایشی و chrome مشترک سایت؛ proxy محلی فشرده‌سازی را حذف می‌کند و gzip-9 جداگانه محاسبه شده است. این اندازهٔ تخمینی انتقال فشرده است، نه سرعت یا transfer واقعی production.

| بخش | اندازهٔ این اجرا |
|---|---:|
| HTML شامل snapshot | حدود ۱۱٫۲ KiB با gzip محاسبه‌شده |
| JS دریافت‌شده، شامل React/Next و اجزای مشترک | حدود ۱۶۶٫۴ KiB با gzip محاسبه‌شده |
| CSS | حدود ۲۱٫۰ KiB با gzip محاسبه‌شده |
| سه فونت IRANSharp، خودِ WOFF2 | حدود ۱۲۴٫۶ KiB |

**کل صفحه زیر ۵۰KB نیست.** محتوای لیست کران دارد، پیوندهای جدید speculative prefetch ندارند، وابستگی جدیدی اضافه نشده و assets سنگین پرتره به این نمونه وارد نشده‌اند. فایل و رفتار پرترهٔ صفحهٔ اصلی بدون تغییر است. شکستن layout مشترک، تغییر preload فونت‌ها یا بهینه‌سازی سراسری bundle نیازمند مرحلهٔ جداست؛ صرفاً برای رسیدن نمایشی به سقف ۵۰KB اعمال نشده‌اند.

## محفوظ

صفحهٔ اصلی، HomeChat، layout و CSS عمومی، پرتره/فونت/تم/منوی اصلی، APIهای چت و گراف معرف، نقش‌ها، P02/P04 و مسیرهای مالی/کیف‌پول تغییری نکرده‌اند. P05 شروع نشده است. هیچ push/deploy یا تغییر Drive انجام نشده؛ تعمیم به صفحهٔ اصلی یا انتقال نهایی تأیید جداگانه می‌خواهد.
