# لایه‌های استقرار هادیران — از نو نساز

هر شکست را به **یک لایه** نسبت بده. لایهٔ سبز را دوباره دست نزن.

| لایه | تمثیل | نشانه | دست نزن اگر |
|---|---|---|---|
| ۰. گیت‌هاب typecheck/build | آزمایش روی میز کار | jobهای Typecheck و Next build | سبز بودند |
| ۱. نصب npm روی لیارا | خرید مصالح | `Using Liara mirror` یا `npm ci` | `added 538 packages` دیدی |
| ۲. `next build` | ساخت اسکلت ساختمان | `Compiled successfully` | همین خط آمده |
| ۳. ایمیج ران‌تایم | بار زدن کامیون اسباب‌کشی | `COPY public` / timeout / `Successfully built` + push | ایمیج push شده |
| ۴. هوک استارت | کلید برق قبل از ورود به خانه | لاگ برنامه خالی، `unhealthy` | خط `[hadiran] pre-start` آمده |
| ۵. خودِ Next | چراغ خانه | `[hadiran] boot` و `/` HTML | خانه باز می‌شود |
| ۶. دیتابیس | یخچال داخل خانه | `/api/health` فیلد `db` | `db: true` |
| ۶.۵ اسکیما | قفسه‌های داخل یخچال | `relation "knowledge" does not exist` / `migrate script: MISSING` | `[hadiran] migrate apply 0000_…` |
| ۷. محتوا / OTP | غذا داخل یخچال | لیست خالی، پیامک نمی‌رود | UI و health زنده‌اند |

`--no-cache` را فقط وقتی ایمیج خراب است بزن. دیپلوی عادی باید از کش لیارا استفاده کند تا به سقف ۱۵ دقیقه نخورد.

سقف ۱۵ دقیقه مال **کل بیلد لیارا** است، نه گیت‌هاب. پلتفرم Next هر استقرار `npm ci` را از نو می‌زند (۴۰ث تا ۲د؛ لایهٔ ۱). بودجه وقتی می‌سوزد که بعد از آن `next build` ساکت بماند — معمولاً چون در فاز بیلد به Postgres وصل شده. migrate فقط `liara_pre_start.sh` / boot؛ در `next build` نه. آلمان و `--no-cache` این گیر را حل نمی‌کنند.

قانون: اگر لایهٔ ۳ سبز است و سایت نیست، مصالح را دوباره نخر (میرور/CI را دست نزن). برو لایهٔ ۴.
