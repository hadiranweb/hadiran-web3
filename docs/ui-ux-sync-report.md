## جداسازی پیش‌نمایش از سایت واقعی

- پیش‌نمایش فقط با `HADIRAN_TEST_MODE=1` **و نبودن** `DATABASE_URL` فعال است.
- در حضور دیتابیس، حتی با فعال‌بودن پرچم تست، ticket نمایشی نمی‌تواند کاربر را احراز هویت کند.
- ورود پیش‌نمایش: `09121234567`، کد `123456`؛ ticket امضاشده، یک‌ساعته و قابل ابطال است.
- ثبت‌ها، پاسخ‌ها و نام نمایشی موقتی و مختص همان ticket هستند؛ دادهٔ واقعی و انتشار عمومی محسوب نمی‌شوند. راه‌اندازی مجدد سرور ticketها را باطل می‌کند.
- ساخت و ذخیرهٔ کالا یا تحلیلگر و عملیات سفارش در محیط بدون دیتابیس غیرفعال است؛ تراکنش یا دسترسی خرید جعلی ساخته نمی‌شود. ویرایشگر CASIO برای بررسی قابل مشاهده است.
- هدر ضد iframe در حالت واقعی `DENY` باقی می‌ماند. استثنا صرفاً پیش‌نمایش داخلیِ صریح و بدون دیتابیس است.
- آزمون ورود بدون کوکی، کوکی‌ها و Authorization و هدر احراز هویت سفارشی را حذف کرد و انتقال ticket، ذخیره، بازخوانی و خروج را بررسی کرد.

## محدودهٔ تضمین و نکات استقرار

این تست‌ها روی **دیتابیس محلیِ دورریختنی** اجرا شدند، نه دیتابیس زندهٔ شما. اتصال SMS.ir، اطلاعات واقعی، HTTPS و سیاست کوکی دامنهٔ اصلی، و فرایند پرداخت بیرون سایت باید در staging شما هم بررسی شوند. ورود iframe نیز روی origin HTTPS شبیه‌سازی‌شده آزموده شده، نه URL بیرونی Arena.

قبل از استقرار:

1. از دیتابیس واقعی پشتیبان بگیرید و patch را در یک branch جدید بررسی کنید.
2. تنظیمات واقعی `DATABASE_URL`، `HADIRAN_JWT_SECRET`، مالک و SMS.ir را از محیط امن تأمین کنید. `HADIRAN_TEST_MODE=0` بماند.
3. `npm ci`، `npm run typecheck`، `npm run lint` و `npm run build` را اجرا کنید.
4. migrationها تا `0014_analyzer_authoring.sql` را طبق فرایند استقرار ریپو اعمال کنید؛ migration مخربِ جایگزین اضافه نشده است.
5. در standalone، پوشه‌های `public` و `.next/static` نیز کنار خروجی قرار گیرند؛ تنظیمات لازم برای trace فایل‌های migration حفظ شده‌اند.
6. روی staging ورود واقعی، پروفایل، ثبت و انتشار، خرید/تأیید و ویرایش/اجرای تحلیلگر را با دادهٔ آزمایشی تکرار کنید.

دو هشدار غیرمسدودکنندهٔ موجود در build باقی‌اند: توصیهٔ Next برای جایگزینی `middleware` با `proxy` و هشدار Edge دربارهٔ لاگ `process.version` در instrumentation. برای جلوگیری از تغییر غیرضروری در مسیر انتشار، در این ادغام بازنویسی نشده‌اند.
